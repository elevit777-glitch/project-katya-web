Потенциальная ценность

Меньше администрирования. Больше движения.

Гипотеза продукта: людям с множеством параллельных интересов и проектов может быть полезна система, где структурирование берёт на себя помощник, а человек сохраняет контроль над решениями. Спрос и эффективность ещё не проверены.

Что реально существует сегодня

Прототип, не готовый сервис

Работают публичные страницы пяти направлений и переходы между ними. Исследовательские записи обновляются через GitHub вручную с помощью ассистента. Мастерская использует локальное хранение в браузере. Автоматическая синхронизация, пользовательские аккаунты, защищённое хранение личных данных и коммерческая модель пока не реализованы.
